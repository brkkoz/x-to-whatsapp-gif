Add “Make GIF” to iPhone Share Sheet

Set up once in Apple's free Shortcuts app. The shortcut opens this site with the shared X link prefilled and automatically starts conversion.

  1. Open Shortcuts → +. Name it Make GIF.
  2. Open shortcut details → enable Show in Share Sheet. Set accepted input to URLs (and optionally Safari web pages if desired).
  3. Add URL Encode action using Shortcut Input as its text.
  4. Add a Text action containing and place the encoded input variable immediately after the equals sign.
  5. Add Open URLs, with the Text action output as its input.
  6. In X, tap Share via… → Make GIF. Safari opens the converter and starts converting. Then tap Share to WhatsApp and choose a chat.

Note: You cannot add an item to X's own built-in app menu. The shortcut appears in the iOS system share sheet; exact wording can differ across iOS versions. This requires a working public deployment URL, not a local file.
